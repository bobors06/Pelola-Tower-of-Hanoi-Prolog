# Tower of Hanoi

A small Tower of Hanoi project made with HTML, CSS, and JavaScript.

## Run in VS Code
1. Extract this folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the VS Code **Live Server** extension and click **Go Live**.

## Features
- Automatic Tower of Hanoi solver
- Animated disk movements
- 3–8 disk difficulty selection
- Slow, normal, and fast animation speeds
- Move counter and minimum move count
- Reset button

No additional libraries or installations are required.
